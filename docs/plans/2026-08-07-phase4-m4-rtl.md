# Phase 4 (M4) Implementation Plan — RTL: Streaming Ternary Denoiser in SystemVerilog

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **Workflow:** planner session dispatches plan-executor per task (Opus 5),
> plan-reviewer per pushed branch (Opus 5), merges per the order below.
> Tasks 1 and 2 may run in parallel; Tasks 3-6 are strictly sequential.
> Task 7 is live integration with Bahadir.

**Goal:** The v1 network (7->16->16->16->16->3) as synthesizable SystemVerilog — line buffers, output-channel-serial ternary PE arrays, shift-round-clamp requant, streaming 5-layer chain with residual head — verified bit-exact against the C++ golden model in Verilator on golden vectors and real-shape frames, with cycle counts reported and a Yosys check proving zero multiplier/DSP cells.

**Architecture (decided with Bahadir 2026-08-07):** Each conv layer computes ONE output channel per cycle (9 x C_in ternary taps into an adder tree, ~144 add/sub for the 16-to-16 layers; ~15-25k LUTs for all five layers; 256x256 at roughly 85-95 fps at 100 MHz). The five layers are a streaming chain, each with its own 2-line buffer (~8 KB per boundary); the noisy RGB rides a delay FIFO to the residual add at the end. valid/ready handshakes everywhere (AXIS semantics, plain naming). A frame streams through once.

**Tech Stack:** SystemVerilog (conservative, Yosys-readable subset: `logic`, `always_ff`/`always_comb`, parameters, generate loops, packed arrays — no interfaces, no classes). Verilator (C++ harnesses that LINK THE C++ GOLDEN MODEL as the in-testbench oracle). Yosys for the zero-multiplier check. Python only for `tools/case_to_mem.py`.

## Global Constraints

- **Bit-exactness is the only acceptance criterion.** Every testbench diffs DUT
  output against the C++ golden model (`sim/`) or checked-in `expected.txt`,
  element-for-element, zero tolerance, exit code 0 only on a perfect match.
- QUANT_SPEC is normative. RTL implements sections 3-6 exactly: zero padding,
  requant = round-half-away via shift (section 4, s in [0,15]), relu after
  requant on layers 1-4 only, residual clamp, 2-bit weight encoding with 11
  illegal.
- Accumulator width per layer: `ACC_W = $clog2(9*C_IN*128) + 3` (spec rule
  +1, plus 2 bits bias headroom). Testbenches assert every loaded bias fits:
  `|bias| < 2**(ACC_W-1) - 9*C_IN*128`.
- No `*`, `/`, or `%` operators anywhere in rtl/ (shifts are fine; index
  arithmetic with constant multiplies is allowed only inside generate/localparam
  elaboration, never in the datapath). The Yosys check enforces the netlist
  side: zero `$mul`/`$div`/`$mod` cells and zero DSP48 after synth_xilinx.
- Weight/bias memories: `$readmemh` of the M1 packer's `.mem` formats (2-bit
  packed bytes, one hex byte per line; biases eight hex chars per line, two's
  complement int32). File paths arrive via `$value$plusargs` inside
  `` `ifndef SYNTHESIS `` blocks; synthesis falls back to parameter-string
  defaults pointing at `synth/case04/` mems (generated by a make rule).
- Runtime-configurable per frame: `width`, `height` (10-bit ports, max 512) and
  per-layer `shift` (4-bit ports). Weights are load-time. Same Verilated binary
  runs every case directory.
- Streams: `valid`/`ready`, data = one pixel word, all channels parallel
  (`C*8` bits, channel 0 in bits [7:0]). Window bus from line buffer:
  `C_IN*9*8` bits, tap index `t = ci*9 + ky*3 + kx` in bits `[t*8 +: 8]`
  (matches QUANT_SPEC flattening with co factored out).
- Every testbench must randomize valid/ready timing (random stalls on both
  sides, seeded 1058) — handshake bugs are the classic way RTL passes a clean
  stream and fails a real one.
- Testbench handshake sampling (Task 3 finding): sample valid/ready/data with
  clk LOW after eval (combinational logic settled), then raise the posedge.
  A single `clk=0;eval();clk=1;eval();` step samples post-edge state — the
  next cycle's handshake — and fails any correct DUT. Follow
  `rtl/tb/tb_linebuffer.cpp`'s `lo()/hi()` pattern in every TB.
- C++ flags for harnesses as repo standard. Verilator builds go to
  `build/<tb_name>/` (gitignored). No emojis anywhere. TDD adapted to RTL:
  write the testbench first, watch it fail (module missing / X output), then
  implement.
- Verilator Makefile mechanics (learned in Task 1, applies to every TB rule):
  `@mkdir -p $(@D)` before verilating (verilator does not create missing
  parents of `--Mdir`), and every user C++ source on the verilator command
  line (`rtl/tb/*.cpp`, `sim/*.cpp`) must be wrapped in `$(abspath ...)` —
  verilator runs its generated sub-make with cwd = `--Mdir`, so relative
  paths break.
- Worktree test invocation for python parts:
  `make test PYTHON=/home/bahadir/ternoise/.venv/bin/python`. `lint` has no
  venv dependency; `rtl_test` and `synth_check` need `$(PYTHON)` to generate
  their `.mem` inputs via `tools.case_to_mem` (from a worktree, pass the
  PYTHON override to those targets too). (Amended per Task 4 review: the
  original "RTL targets have no venv dependency" contradicted the plan's own
  mem-generation rules.)
- CI changes are deferred to Task 7 (workflow file edits stay with the planner).

```python
"""Golden case dir -> $readmemh inputs for the RTL testbenches.

Emits w{i}.mem (2-bit packed weights), b{i}.mem (int32 two's complement),
and meta.txt (type/chans/shift/relu/dims) per QUANT_SPEC sections 6-7.
"""
import argparse
import json
from pathlib import Path

from tools.pack_weights import bias_to_mem, pack, to_mem, unpack
from vectors.io_text import load_tensor

CHANS_V1 = [7, 16, 16, 16, 16, 3]


def convert(case_dir, out_dir):
    case, out = Path(case_dir), Path(out_dir)
    out.mkdir(parents=True, exist_ok=True)
    p = json.loads((case / "params.json").read_text())
    x = load_tensor(case / "input.txt")
    lines = []
    if p["type"] == "conv":
        w = load_tensor(case / "weights.txt")
        (out / "w1.mem").write_text(to_mem(pack(w)))
        (out / "b1.mem").write_text(bias_to_mem(load_tensor(case / "bias.txt")))
        lines += ["type conv", "layers 1",
                  f"chans {w.shape[1]} {w.shape[0]}",
                  f"shift {p['shift']}", f"relu {p['relu']}"]
    else:
        shifts, relus = [], []
        for i, layer in enumerate(p["layers"], start=1):
            if p["type"] == "network_packed":
                raw = (case / f"w{i}.bin").read_bytes()
                n = CHANS_V1[i] * CHANS_V1[i - 1] * 9
                unpack(raw, (n,))          # validates: raises on code 11
            else:
                raw = pack(load_tensor(case / f"w{i}.txt"))
            (out / f"w{i}.mem").write_text(to_mem(raw))
            (out / f"b{i}.mem").write_text(
                bias_to_mem(load_tensor(case / f"b{i}.txt")))
            shifts.append(str(layer["shift"]))
            relus.append(str(layer["relu"]))
        lines += ["type network", "layers 5",
                  "chans " + " ".join(str(c) for c in CHANS_V1),
                  "shift " + " ".join(shifts), "relu " + " ".join(relus)]
    lines += [f"height {x.shape[1]}", f"width {x.shape[2]}"]
    (out / "meta.txt").write_text("\n".join(lines) + "\n")


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("case_dir")
    ap.add_argument("--out", required=True)
    convert(**vars(ap.parse_args()))


if __name__ == "__main__":
    main()
```

**Interfaces:**
- Produces the module every conv layer sits behind:

```systemverilog
module linebuffer #(
    parameter int C     = 16,          // channels
    parameter int W_MAX = 512
) (
    input  logic                clk,
    input  logic                rst,
    input  logic [9:0]          width,   // runtime frame dims, stable per frame
    input  logic [9:0]          height,
    input  logic                s_valid, // pixel-word in: all C channels of one pixel
    output logic                s_ready,
    input  logic [C*8-1:0]      s_data,  // channel ci in bits [ci*8 +: 8]
    output logic                m_valid, // window out, raster order, one per pixel
    input  logic                m_ready,
    output logic [C*9*8-1:0]    m_win    // tap t = ci*9+ky*3+kx in bits [t*8 +: 8]
);
```

- **Behavioral contract (normative):** for every input frame of `height x width`
  pixel-words in raster order, the module emits exactly `height x width`
  windows in raster order. The window for position (y, x) contains input pixel
  (y+ky-1, x+kx-1) at tap (ky, kx), with taps outside the frame equal to zero
  (QUANT_SPEC zero padding). Backpressure on `m_ready` must stall the input
  (via `s_ready`) without dropping or duplicating; the module must accept
  back-to-back frames without reset between them.
- Implementation guidance (executor's latitude, contract above is what's
  tested): two `W_MAX x C*8` line RAMs plus a 3-column register window; output
  runs one row behind input; a flush phase emits the last row (bottom taps
  zeroed) after the frame's final input pixel; zero-mux on coordinate
  comparison for all borders. No multipliers — address arithmetic is counters
  and adds only.

- [ ] **Step 1: Write the failing testbench (the oracle is exhaustive)**

`rtl/tb/tb_linebuffer.cpp` — full reference implementation:

```cpp
// Streams random frames through Vlinebuffer with random stalls; checks every
// window against a software reference. Bit-exact, zero tolerance.
#include "Vlinebuffer.h"
#include "verilated.h"
#include <cstdint>
#include <cstdio>
#include <random>
#include <vector>

static constexpr int C = 16;

struct Ref {  // golden windows for one frame
    int h, w;
    std::vector<int8_t> px;  // [y*w+x][c] flattened as (y*w+x)*C + c
    int8_t at(int y, int x, int c) const {
        if (y < 0 || y >= h || x < 0 || x >= w) return 0;
        return px[(y * (size_t)w + x) * C + c];
    }
};

int main(int argc, char** argv) {
    VerilatedContext ctx;
    ctx.commandArgs(argc, argv);
    Vlinebuffer dut{&ctx};
    std::mt19937 rng(1058);
    auto step = [&] { dut.clk = 0; dut.eval(); dut.clk = 1; dut.eval(); };

    const int sizes[][2] = {{3, 3}, {4, 7}, {16, 16}, {31, 5}, {64, 64}};
    for (auto& sz : sizes) {
        const int H = sz[0], W = sz[1];
        Ref ref{H, W, {}};
        ref.px.resize((size_t)H * W * C);
        for (auto& v : ref.px) v = (int8_t)(rng() & 0xff);

        dut.rst = 1; step(); step(); dut.rst = 0;
        dut.width = W; dut.height = H;

        size_t in_i = 0, out_i = 0, total = (size_t)H * W;
        long cycles = 0;
        while (out_i < total && cycles < 4000000) {
            ++cycles;
            // drive input with random stalls
            bool drive = in_i < total && (rng() & 3) != 0;
            dut.s_valid = drive;
            if (drive)
                for (int c = 0; c < C; ++c)
                    ((uint8_t*)&dut.s_data)[c] = (uint8_t)ref.px[in_i * C + c];
            dut.m_ready = (rng() & 7) != 0;   // random downstream stalls
            step();
            if (dut.s_valid && dut.s_ready) ++in_i;
            if (dut.m_valid && dut.m_ready) {
                const int y = (int)(out_i / W), x = (int)(out_i % W);
                for (int c = 0; c < C; ++c)
                    for (int ky = 0; ky < 3; ++ky)
                        for (int kx = 0; kx < 3; ++kx) {
                            const int t = c * 9 + ky * 3 + kx;
                            const int8_t got = (int8_t)((uint8_t*)&dut.m_win)[t];
                            const int8_t want = ref.at(y + ky - 1, x + kx - 1, c);
                            if (got != want) {
                                std::printf("FAIL %dx%d pix(%d,%d) tap(c=%d,ky=%d,kx=%d): got %d want %d\n",
                                            H, W, y, x, c, ky, kx, got, want);
                                return 1;
                            }
                        }
                ++out_i;
            }
        }
        if (out_i != total) { std::printf("FAIL %dx%d: only %zu/%zu windows\n", H, W, out_i, total); return 1; }
        std::printf("ok %dx%d (%ld cycles)\n", H, W, cycles);
    }
    std::puts("PASS tb_linebuffer");
    return 0;
}
```

(Note: `m_win` is wider than 64 bits, so Verilator exposes it as a word array —
the byte-pointer access above works on little-endian x86; the executor should
adapt to `VlWide` accessors if -Wall flags it. Two consecutive frames without
reset must also be exercised — duplicate the 16x16 entry back-to-back.)

```systemverilog
    input  logic                  rst,
    input  logic [3:0]            shift,
    input  logic                  s_valid,   // window in (from linebuffer)
    output logic                  s_ready,
    input  logic [C_IN*9*8-1:0]   s_win,
    output logic                  m_valid,   // pixel word out, all C_OUT channels
    input  logic                  m_ready,
    output logic [C_OUT*8-1:0]    m_data
);
```

- **Cycle behavior (normative):** accept a window when idle; over the next
  C_OUT cycles compute output channel co = 0..C_OUT-1 (decode 9*C_IN weight
  codes for co, adder-tree them with the bias, requant with `shift`, relu if
  RELU), assembling `m_data`; then assert `m_valid` until accepted. Throughput
  <= C_OUT + 2 cycles per pixel is acceptable; report the measured number.
- Weight storage: `$readmemh` bytes into `logic [7:0] wmem [0:NBYTES-1]`,
  `NBYTES = (C_OUT*C_IN*9 + 3) / 4`; code for (co, tap t) at flat index
  `idx = co*C_IN*9 + t`, bits `wmem[idx/4][2*(idx%4) +: 2]` — where `idx/4`
  and `idx%4` are elaborated as shifts/masks (`idx >> 2`, `idx & 2'b11`),
  never `/`/`%` operators. Bias: 32-bit words, truncated to ACC_W on use.
  Under `` `ifndef SYNTHESIS ``: `$value$plusargs({WKEY, "=%s"}, path)`
  overrides the file; an initial block `$fatal`s on any code == 2'b11.

- [ ] **Step 1: `rtl/requant.sv` + its testbench FIRST (spec section 4 in silicon)**

```systemverilog
module requant #(parameter int ACC_W = 18) (
    input  logic signed [ACC_W-1:0] acc,
    input  logic [3:0]              shift,
    output logic signed [7:0]       q
);
    // rha(acc,s) then clamp, per QUANT_SPEC section 4. One headroom bit for
    // the +half; magnitude path realizes round-half-away with a logical shift.
    logic signed [ACC_W:0] acc_x;
    logic [ACC_W:0]        mag, half, shifted;
    logic signed [ACC_W:0] rounded;
    always_comb begin
        acc_x   = {acc[ACC_W-1], acc};
        mag     = acc_x[ACC_W] ? unsigned'(-acc_x) : unsigned'(acc_x);
        half    = '0;
        if (shift != 0) half = ({{ACC_W{1'b0}}, 1'b1} << (shift - 4'd1));
        shifted = (mag + half) >> shift;
        rounded = acc_x[ACC_W] ? -signed'(shifted) : signed'(shifted);
        if (rounded > $signed({{(ACC_W-7){1'b0}}, 8'sd127}))       q = 8'sd127;
        else if (rounded < -$signed({{(ACC_W-7){1'b0}}, 8'sd128})) q = -8'sd128;
        else                                                        q = rounded[7:0];
    end
endmodule
```

```cpp

#include "Vrequant.h"
#include "verilated.h"
#include "../../sim/ops.h"
#include <cstdio>

int main(int argc, char** argv) {
    VerilatedContext ctx;
    ctx.commandArgs(argc, argv);
    Vrequant dut{&ctx};
    // 1) the 11 normative rows from QUANT_SPEC section 4
    const long long spec[][3] = {{0,0,0},{127,0,127},{200,0,127},{-200,0,-128},
        {5,1,3},{-5,1,-3},{3,1,2},{-3,1,-2},{2,2,1},{-2,2,-1},{36864,5,127}};
    for (auto& r : spec) {
        dut.acc = (int)r[0]; dut.shift = (int)r[1]; dut.eval();
        if ((int8_t)dut.q != (int8_t)r[2]) { std::printf("FAIL spec acc=%lld s=%lld got=%d\n", r[0], r[1], (int8_t)dut.q); return 1; }
    }
    // 2) exhaustive: every acc in [-100000, 100000], every shift in [0,15],
    //    against sim/ops.cpp requant (the C++ golden model IS the oracle)
    for (long long a = -100000; a <= 100000; ++a)
        for (int s = 0; s < 16; ++s) {
            dut.acc = (int)a; dut.shift = s; dut.eval();
            if ((int8_t)dut.q != (int8_t)requant(a, s)) { std::printf("FAIL acc=%lld s=%d got=%d want=%lld\n", a, s, (int8_t)dut.q, requant(a, s)); return 1; }
        }
    std::puts("PASS tb_requant");
    return 0;
}
```

```systemverilog
module delay_fifo #(
    parameter int WIDTH = 24,          // 3 channels x 8
    parameter int DEPTH_LOG2 = 13      // 8192 > 16 lines x 512 - covers chain latency

    input  logic         rst,
```

- Structure: 5 x (linebuffer -> conv3x3) with CHANS 7->16->16->16->16->3,
  RELU on instances 1-4 only, WKEY/BKEY parameters "w1".."w5"/"b1".."b5".
  Input RGB (channels 0-2 of `s_data`) is pushed into `delay_fifo` on every
  accepted input pixel; the output stage pops one FIFO entry per layer-5
  pixel and computes `clamp(x + r, -128, 127)` per channel (9-bit signed
  adds, comparison clamp — no multipliers). Stream ordering guarantees
  FIFO/pixel alignment; the bit-exact diff catches any violation.
- **Residual clamp note:** this is QUANT_SPEC section 5's residual head; the
  adder is 9-bit signed, clamp bounds are constants.
- **Timing note (Task 3 review):** every stage's `s_ready` is combinational
  from its downstream `m_ready`, so the chained top carries one ready path
  from output back to input. Fine for simulation and the bit-exact claim;
  Task 6's stat step should mention it, and if synthesis timing ever
  complains, the fix is a registered-ready (skid) stage between layers.
